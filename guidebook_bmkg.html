🖥 Bab 1 — Gambaran Sistem

🖥 Gambaran Umum & Arsitektur Sistem

🎯
Tujuan Sistem

Sistem ini dibangun untuk mendigitalisasi seluruh proses tata kelola persuratan Tim MTG 4 menggantikan buku agenda manual.

✓ Pencatatan surat masuk & keluar
✓ Manajemen disposisi pimpinan
✓ Arsip berkas digital terstruktur
✓ Laporan statistik periodik
✓ Akses multi-pengguna terautentikasi

Stack Teknologi

🗄 Database MySQL / MariaDB
🎨 Frontend Bootstrap 5
📊 Tabel Data DataTables.js
📈 Grafik Chart.js
🔐 Autentikasi PHP Session Guard
🗃
Struktur Database

Tgl Surat, Tgl Terima, No. Surat, Jenis, Deskripsi, Asal, Jumlah, Disposisi, File, Status

📋 Tabel: surat_keluar
Nomor, Nama Surat, Tanggal, Tertuju, Jumlah, File Berkas

🔐 Bab 2 — Autentikasi Akun

🔐 Petunjuk Akses & Autentikasi Akun

📝
Registrasi Akun Baru
1

Buka peramban web (Chrome / Firefox / Edge)

2

Akses URL sistem dan klik "Daftar di sini" atau buka register.php

3

Isi formulir: Nama Depan, Nama Belakang, Email, Password, Konfirmasi Password

4

Klik tombol "Daftar Sekarang"

5

Sistem menampilkan notifikasi sukses dan diarahkan ke halaman login

ℹ️ Jika email sudah terdaftar, sistem akan menolak dan meminta email lain.
🔑
Login ke Sistem
1

Akses halaman login.php

2

Masukkan Email yang sudah terdaftar

3

Masukkan Password akun Anda

4

Centang "Tetap Masuk" bila menggunakan komputer kerja pribadi

5

Klik tombol hijau "Masuk" — sistem akan mengarahkan ke Dashboard

✅ Email aktif tampil di pojok kiri bawah sidebar setelah login berhasil.
🚪
Logout dari Sistem
1

Gulir ke bagian "AKUN" di sidebar kiri

2

Klik tombol merah "Logout"

3

Sesi dimusnahkan secara aman & diarahkan ke login

🔒 Keamanan: Sistem dilengkapi Session Guard — halaman tidak bisa diakses langsung via URL tanpa login yang sah.

✏️ Bab 4.2 — Aksi Data Surat

✏️ Aksi Data Surat — Edit, Hapus, Status & Lihat Berkas

🔄
Toggle Status Penyelesaian

Sistem menyediakan tombol status instan tanpa perlu membuka form edit:

❌ Belum
→ Klik →

Klik tombol "Belum" → otomatis berubah menjadi "Selesai". Klik lagi untuk membatalkan.

1

2

📥 Alur Disposisi Surat Masuk
1

Penerimaan: Surat fisik/elektronik diterima staf MTG 4

2

Digitalisasi: Berkas dipindai (scan) ke PDF/JPG berkualitas jelas

3

Pencatatan: Buka Modul Administrasi BMKG → input tanggal, perihal, pengirim, upload berkas scan

4

Disposisi: Isi kolom Tindak Lanjut KASGEOF & Tindak Lanjut Datin sesuai instruksi pimpinan

5

Pelaksanaan: Anggota tim melaksanakan instruksi (analisis seismisitas, sosialisasi mitigasi, dsb.)

6

Penutupan: Klik tombol status → Selesai ✅

📤 Alur Pengarsipan Surat Keluar
1

Konsep surat disetujui & ditandatangani pimpinan, dibubuhi nomor surat resmi stasiun

2

Input data pada modul Surat Keluar dan modul Administrasi BMKG

3

Berkas digital berstempel resmi diunggah sebagai arsip permanen

4

Surat dikirimkan kepada instansi mitra / tertuju

🔧 Bab 6 — Troubleshooting

🔧 Panduan Penanganan Masalah (Troubleshooting)

No Gejala Masalah Penyebab Umum Solusi Perbaikan
1 Notifikasi "Ekstensi file tidak diizinkan!" saat menyimpan data Berkas yang diunggah memiliki ekstensi tidak diizinkan (misal .zip, .rar, .exe) Ubah berkas ke format PDF, DOC/DOCX, atau Gambar (JPG/PNG) sebelum diunggah
2 Pesan "Email sudah terdaftar!" saat registrasi Email yang dimasukkan sudah ada di tabel basis data Gunakan email berbeda atau langsung login jika akun tersebut milik Anda
3 Halaman langsung kembali ke login.php saat membuka halaman lain Sesi login telah habis (expired) atau belum melakukan login yang sah Masuk kembali dengan memasukkan email dan password di login.php
4 File berkas tidak dapat dibuka (File not found / 404) Berkas fisik terhapus dari folder file/ di server hosting / komputer lokal Hubungi administrator untuk memeriksa folder file/ dan hak akses (permissions)
5 Saat mencetak laporan, sidebar dan navigasi ikut tercetak Peramban tidak menerapkan aturan print-media dengan benar Gunakan tombol Cetak Laporan di web dan centang opsi "Background graphics" pada pratinjau cetak
6 Galat "Koneksi database gagal" Layanan MySQL pada XAMPP berhenti atau parameter koneksi di function.php tidak cocok Buka XAMPP Control Panel, pastikan Apache dan MySQL berstatus Running (hijau). Periksa konfigurasi di function.php
